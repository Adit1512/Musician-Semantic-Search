# 🎵 Musician Semantic Search Dashboard

A lightweight **Semantic Web dashboard** to instantly retrieve structured profiles of Bands / Musicians directly from **DBpedia (Linked Open Data)** — without needing a manual database.

Built using:
- HTML
- CSS
- Vanilla JavaScript
- SPARQL
- DBpedia Linked Data

---

## 🚀 Project Overview

The entertainment industry often requires quick access to artist information without maintaining internal datasets.

This application allows users to search for:

> Band / Musician name → instantly retrieve semantic data

All data is fetched live from **DBpedia**, ensuring:
- Up-to-date information
- No manual storage
- Scalable knowledge access
